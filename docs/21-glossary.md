# Glosario

Última revisión documental: 2026-09-10.

| Término | Significado | Evidencia |
|---|---|---|
| Astro | Framework que genera el sitio. | `package.json`, `astro.config.mjs` |
| HUD | Panel visual configurable con estética de interfaz. | `HudPanel.astro` |
| Slot | Contenido insertado por un componente consumidor. | `Layout.astro`, `HudPanel.astro` |
| `dist/` | Salida generada por el build. | Scripts de `package.json` |
